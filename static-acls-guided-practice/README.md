# Static Access Control Lists (ACLs) – Guided Practice

## Objective
Practice configuring static ACLs to control network traffic and enforce security policies across network segments.

## Technologies Used
- Cisco Packet Tracer
- Routers
- Static ACLs
- IP Addressing

## Tasks Performed
- Created ACL rules to permit and deny specific traffic
- Applied ACLs to router interfaces
- Verified filtering using ping tests
- Analyzed rule order and how it impacts traffic flow

## Skills Demonstrated
Secure router configuration, traffic filtering, and troubleshooting ACL behavior.
