# Static Access Control Lists (ACLs) – Practical Assignment

## Objective
Configure and apply static access control lists (ACLs) to control network traffic between subnets while allowing authorized communication.

## Technologies Used
- Cisco Packet Tracer
- Routers and Switches
- Static Access Control Lists (ACLs)
- IP Addressing and Subnetting

## Tasks Performed
- Configured static ACLs to permit and deny traffic based on requirements
- Applied ACLs to router interfaces in the correct direction (in/out)
- Verified ACL behavior using ping tests and CLI show commands
- Troubleshot rule order and ACL placement

## Security Focus
Demonstrates network traffic filtering and basic security policy enforcement using ACLs.
