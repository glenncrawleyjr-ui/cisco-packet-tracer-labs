# Final Practical – Routing and Internet Connectivity (Cisco Packet Tracer)

## Objective
Configure routing and network connectivity to allow internal networks to communicate while maintaining correct routing behavior.

## Technologies Used
- Cisco Packet Tracer
- Routers and Switches
- IP Addressing and Subnetting
- Routing fundamentals (static and/or dynamic)

## Tasks Performed
- Configured router interfaces and addressing
- Implemented routing between networks
- Verified routing tables and end-to-end connectivity
- Troubleshot connectivity issues and validated external/internet reachability

## Skills Demonstrated
Routing, troubleshooting, and structured network configuration.
