# Cisco Packet Tracer Labs

This repository contains hands-on networking and security labs completed using Cisco Packet Tracer as part of my cybersecurity coursework.

## Lab Topics
- Static Access Control Lists (ACLs)
- Network traffic filtering and security enforcement
- Routing and internet connectivity
- Network troubleshooting and verification

## Tools & Technologies
- Cisco Packet Tracer
- Routers and Switches
- IP Addressing & Subnetting
- Static Routing
- Access Control Lists (ACLs)

## Purpose
These labs demonstrate practical networking and security fundamentals relevant to entry-level cybersecurity, SOC, and IT support roles.
